# Playbook de mesure de la valeur

## 1. Cadrer l'hypothèse

Pour chaque décision ou initiative :
- valeur attendue, type, propriétaire, bénéficiaire ;
- baseline, cible, unité, devise, période ;
- conditions de réussite et hypothèses ;
- attribution prévue ;
- coût de la mesure et source de données.

## 2. Mesurer

- baseline avant changement ;
- observation après une période convenue ;
- même unité, même périmètre, même source ;
- preuve et date ;
- confiance et limites.

## 3. Attribuer

Choisir explicitement :
- directe ;
- contribution ;
- activation ;
- inconnue.

Si plusieurs facteurs contribuent, ne pas revendiquer 100 % du bénéfice.

## 4. Comparer

- écart absolu et relatif ;
- atteint / en écart ;
- valeur à risque ;
- valeur déplacée ou détruite ;
- coût du délai.

## 5. Apprendre

- condition de réutilisation ;
- situation source ;
- outcome source ;
- réutilisation observée ;
- mise à jour du Learning.

## 6. Revue

30 / 60 / 90 jours :
- la valeur est-elle réalisée ?
- l'attribution tient-elle ?
- le bénéfice est-il durable ?
- faut-il corriger, arrêter ou généraliser ?

## Dette de mesure

Une valeur `hypothese` sans observation, ou une initiative sans outcome, est une dette de mesure. Elle doit être visible
dans le portefeuille et revue, pas masquée par des compteurs d'activité.

## Industries

- **MSP / PMI / Prince2** : benefits register, business case, post-implementation review.
- **SAFe** : epic hypothesis, lean business case, leading/lagging indicators, WSJF, cost of delay.
- **OKR** : baseline, target, check-in, grading.
- **Lean / A3** : target/current condition, countermeasure, results.
- **SRE** : error budget, incident cost, reliability.
- **FinOps** : coût, usage, valeur, unit economics.
- **COSO / ISO 31000** : risque, contrôle, perte évitée.
- **Théorie du changement** : inputs → activities → outputs → outcomes → impact.

## Règle finale

Une valeur sans baseline, preuve, attribution et revue est une **hypothèse**, pas un résultat.
