Le jumeau apprend ce qui lui échappe

Un besoin ouvert est un écart observé entre un état réel et un état requis — non encore satisfait ni expliqué. Des détecteurs déterministes lisent les signaux ; des hypothèses rivales s'affrontent ; un NEED porte toujours l'observation qui le tuerait ; chaque besoin confirmé émet un pari daté ; le taux de confirmation par signature réécrit le détecteur suivant. Le learning n'est pas un texte — c'est un poids.
