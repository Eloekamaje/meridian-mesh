- `db.cases` peut être remplacé par `PostgresTravailCollection` : filtres Mongo utilisés

  `replace_one`, `bulk_write`.
- Activation : `JUMEAU_TRAVAIL_WRITE=postgres` + `JUMEAU_TRAVAIL_STORE=postgres`, puis
  redémarrage. Les pièces jointes restent dans Mongo.
- Fumée réelle sur `demo` : lecture Actualités, création, GET, PATCH, suppression d'une
  conversation ; `travail` revient à 3 cas après nettoyage.
- Écritures sérialisées par tenant via advisory lock Postgres + verrou asyncio ;
  pas de rollback automatique Postgres → Mongo.
