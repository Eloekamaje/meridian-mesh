## Règles

- Le PRD décrit le **produit cible**, pas l'état du code.
- Les exigences utilisent RFC 2119 (`DOIT`, `DEVRAIT`, `PEUT`).
- Les décisions structurantes sont tracées dans `docs/adr/`.
- Toute évolution de périmètre ou de modèle passe par une révision de version du PRD et, si nécessaire, un ADR.
- Un écart d'implémentation est un **chantier**, pas une exception silencieuse.
