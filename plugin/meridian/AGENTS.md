# Méridian — instructions plugin

- Utiliser les skills `meridian-incident-ops`, `meridian-architecture-impact`, `meridian-benefits-okr` selon la question.
- Pour toute analyse, appeler `meridian_analyser` ; ne jamais fabriquer de faits, de preuves ou de relations.
- Le **socle** est invariant : les profils changent la lecture, jamais les faits.
- Les actions sont des propositions ; aucune écriture, promotion, décision ou exécution.
- Un profil inconnu reste en lecture seule.
- Signaler les limites, preuves périmées et incertitudes.
- Les domain packs `paiements` et `risque` sont en lecture seule ; ne pas en ajouter sans validation explicite.
