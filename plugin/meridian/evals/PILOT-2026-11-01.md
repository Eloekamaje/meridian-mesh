# Pilote local — 2026-11-01

Périmètre : installation reproductible du plugin et mesure des deux workflows pilotes
(`incident-paiements`, `changement-reglementaire`) sur le runtime backend DeepSeek.

**Claude Code n'a pas été utilisé pour les runs réels.** Le runner
[`run_deepseek.py`](run_deepseek.py) appelle directement `POST /api/aurora/demander` sur un backend
configuré avec `JUMEAU_MODELE=deepseek` et `DEEPSEEK_API_KEY` (clé jamais affichée). L'ancienne
tentative Claude Code est conservée plus bas comme historique, mais elle ne fait pas partie de la
mesure.

## Installation

```bash
scripts/install-meridian-plugin.sh --check
```

Résultat : manifeste `meridian.plugin/1` valide (4 skills, 3 agents, 2 domain packs,
policy, contrat, MCP), et liens `.claude/skills/meridian-*` présents. Le script imprime
la commande `claude mcp add meridian --scope project ...` sans toucher à `~/.claude`.

```bash

  --scenario ../plugin/meridian/evals/scenarios/incident-paiements.json \
  --scenario ../plugin/meridian/evals/scenarios/changement-reglementaire.json \
  --runs 1 --max-budget-usd 1.00 --tenant demo --dry-run
```

Sortie : `/tmp/meridian-dryrun-all-20261101.txt` (exit `0`, 6 commandes = 3 bras × 2
scénarios). Vérifications faites :

  `PYTHONPATH` racine, tenant `demo`, persona `architecte` ;
- `skill+mcp` : `Skill,Read` + tools MCP du scénario, cwd racine du dépôt ;
- `checklist+mcp` : même MCP, checklist générique, cwd vide ;
- `data-only` : pack JSON chargé (aucune erreur), sans MCP ni `--strict-mcp-config` ;
- skills visibles : `incident-ops`, `architecture-impact`, `benefits-okr`,
  `enterprise-portfolio`.

## Run réel DeepSeek (Claude non utilisé)

Backend local temporaire, port `8002` :

```bash
cd backend
JUMEAU_MODELE=deepseek .venv/bin/python -m uvicorn server:app \
  --host 127.0.0.1 --port 8002
```

Runner, depuis `backend/` :

```bash
PYTHONPATH=..:../backend .venv/bin/python ../plugin/meridian/evals/run_deepseek.py \
  --scenario ../plugin/meridian/evals/scenarios/incident-paiements.json \
  --scenario ../plugin/meridian/evals/scenarios/changement-reglementaire.json \
  --api-url http://127.0.0.1:8002/api --tenant demo --runs 1 \
  --output /tmp/meridian-deepseek-pilot-20261101
```

Résultat : **2/2 runs complets** (HTTP `200`, texte non vide), modèle rapporté
`deepseek-chat`, coût estimé total **0,098954 USD**.

| Scénario | Durée | Jetons entrée | Jetons sortie | Jetons total | Coût estimé | Critères |
|---|---:|---:|---:|---:|---:|---|
| `incident-paiements` | 36,942 s | 188 426 | 3 272 | 191 698 | 0,054474 USD | **échec** |
| `changement-reglementaire` | 31,454 s | 150 878 | 3 403 | 154 281 | 0,044480 USD | **échec** |

Les deux réponses sont honnêtes : Conduit ne contient ni paiement ni règle R-118, et le modèle
signale l'absence au lieu d'inventer. Les critères de scénario échouent néanmoins **0/2** :

- les Twins de sélection (`paiements`, `comptes`, `fraude`) n'existent pas dans le tenant `demo` ;
  seuls `conduit`, `gestion-des-articles` et `meridian` sont visibles ;
- `/aurora/demander` renvoie une réponse Flore en prose, pas le contrat de sections du plugin
  (`socle`, `lecture`, `actions`, `autorite`, `prochaines_etapes`), donc les critères de sections
  ne peuvent pas passer tels quels.

Artefacts : `/tmp/meridian-deepseek-pilot-20261101/` (`summary.json`, `REPORT.md`, une réponse
brute et un bilan par scénario). Aucun secret n'est écrit ni affiché.

## Limites

- Le tenant `demo` ne contient que les 3 jumeaux réels (`conduit`, `gestion-des-articles`,
  `meridian`) ; les Twins `paiements`, `comptes`, `fraude`, `support` des scénarios sont absents.
  Les packs `evals/data/*.json` restent des instantanés valides, pas l'état du tenant.
- Le backend répond en prose Flore, pas au format de sections attendu par les scénarios plugin.
  Un critère de section en échec ne prouve pas un défaut du workflow.
- Un run par scénario : aucune moyenne, aucun test statistique.
- Aucune revue humaine, aucun outcome réel ; ce pilote ne démontre pas la production readiness.
- Le coût est une estimation du backend (`usage.cout`), pas une facture.
