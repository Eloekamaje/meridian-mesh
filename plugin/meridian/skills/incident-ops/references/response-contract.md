# Contrat de réponse incident

Le résultat doit toujours contenir :

- `socle.faits` : faits et propositions sourcées ;
- `socle.preuves` : identifiants et locators ;
- `socle.incertitudes` : hypothèses et questions ;
- `socle.limites` : sources absentes ou partielles ;
- `lecture.incident`, `lecture.sla`, `lecture.mitigation`, `lecture.processus` ;
- `actions` : propositions, jamais exécutées ;
- `autorite` : `lecture` ou `proposition` ;
- `prochaines_etapes`.

Ne jamais transformer une hypothèse en cause certaine. Une preuve périmée est signalée.
