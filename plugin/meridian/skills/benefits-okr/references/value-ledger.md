# Value Ledger

Une ligne de valeur contient : type, propriétaire, bénéficiaire, baseline, cible, observe,
unité, devise, période, attribution, confiance, preuves, coût, risque, statut, revue.

Statuts : `hypothese`, `mesuree`, `validee`, `realisee`, `deplacee`, `detruite`, `abandonnee`.

Règles : pas de baseline = pas de valeur réalisée ; pas de preuve = pas de validation ;
pas de contre-factuel = pas d'attribution directe ; devises et unités jamais additionnées.
